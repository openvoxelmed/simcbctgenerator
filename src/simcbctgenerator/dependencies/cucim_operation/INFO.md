# cuCIM distance transform

This is just a copy of the function from the cuCIM library. As we had a lot of troubles with the package in Windows 11, we decided to grap the only function we needed from the library. This is taken from version 23.2.0. Please refer for more detail to the [official github repository](https://github.com/rapidsai/cucim).

Only difference is that here only the 3d version is supported as we only needed that functionality.
